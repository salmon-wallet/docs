Versioned release notes are not yet maintained in this documentation. Until they are available, use the official [Salmon blog](https://medium.com/@salmonwallet) and the release history of the relevant source repository.

Future entries should include:

- Version number and release date.
- Supported platforms and rollout status.
- User-visible changes and fixes.
- Security-relevant changes and required user actions.
- Known issues, migrations, and compatibility notes.
- Links to the corresponding source tag or pull requests.

Announcements should not be treated as confirmation that a release is available on every platform. Verify the version shown by your installed wallet.
