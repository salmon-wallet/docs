Salmon is an open-source, self-custodial wallet. The code is public, your keys remain under your control, and every sensitive action requires your approval.

## Available platforms

Salmon currently ships as:

- A Chrome browser extension. It opens in the browser side panel.
- An Android application, currently labelled Beta.

The source can produce a Firefox build, but the official website does not currently publish a Firefox store listing. The iOS application is not yet generally available. The standalone web wallet was retired on September 2, 2026.

Always start at [salmonwallet.io](https://salmonwallet.io) to find current, official download links.

## Supported networks

The released wallet supports Solana and Bitcoin:

| Blockchain | Standard network | Developer networks |
| --- | --- | --- |
| Solana | Mainnet | Devnet and testnet |
| Bitcoin | Mainnet | Testnet |

Developer networks are hidden during normal use.

## What you can do

- Create a new wallet or restore one from a recovery phrase.
- Create and switch between derived accounts.
- View balances and transaction history.
- Send and receive Solana assets, and receive BTC.
- View, send, and burn Solana collectibles.
- Connect the browser extension to Solana dApps.
- Use Mobile Wallet Adapter with compatible dApps on Android.
- Manage contacts, trusted apps, language, currency, appearance, and blockchain explorer preferences.

See [current feature availability](/getting-started/using-salmon#current-availability) for the differences between extension and mobile, including current Bitcoin and swap limitations.

::warning
Salmon support will never need your recovery phrase, private key, or password. Anyone with your recovery phrase or private key can control the associated assets.
::
