## Receive assets

1. Select the intended account and network.
2. Choose **Receive**.
3. Copy the address or show its QR code.
4. Confirm that the sender is using the same blockchain and network.

Solana and Bitcoin addresses are not interchangeable. Mainnet and developer-network funds are also separate. A watch-only account can receive assets because receiving only requires its public address.

## Send Solana assets

1. Select a Solana asset and choose **Send**.
2. Enter or scan the destination address.
3. Enter the amount.
4. Review the destination, network, amount, and estimated fee.
5. Approve and wait for the submitted transaction to resolve.

Salmon tracks pending Solana transactions across navigation, locking, and application restarts. A submission can have an unknown outcome when connectivity is interrupted; check the transaction in the selected blockchain explorer before sending again.

Watch-only accounts cannot send because they do not contain signing keys.

Bitcoin balances, activity, and UTXOs are available for inspection. Bitcoin sending is not currently supported end to end, so do not deposit funds on the assumption that this release can build every required Bitcoin transaction.

The swap engine and API exist, but the product entry points are closed in the current extension and mobile release. This documentation will add the user flow when the feature is exposed again.

## Activity and explorers

Open **Activity** to inspect recent transactions. Choose the preferred explorer in Settings to open an independent public view of a transaction.

Developer networks use different explorer URLs. Always confirm the explorer indicates the expected cluster or network.

## Solana collectibles

Salmon can list, inspect, send, and burn Solana collectibles from accounts that contain signing keys. Burning is irreversible. Review the selected mint and account before approving.

The wallet separates loading failures from an empty collection. If collectibles fail to load, retry rather than assuming the account owns none.

## Contacts and addresses

The address book stores named contacts. Domain resolution may be available for supported naming systems, but always compare the resolved address before approving a transfer.

## Developer networks

Developer mode exposes non-production Solana networks and Bitcoin testnet when supported by the active wallet. Assets on these networks have no mainnet value. Switch back to mainnet before using production funds.
