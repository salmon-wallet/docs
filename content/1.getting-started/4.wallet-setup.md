Salmon offers two setup paths. Choose **Create** for a new wallet or **Restore** when you already control a compatible recovery phrase.

## Create a wallet

1. Choose **Create wallet**.
2. Read and accept the recovery warning.
3. Record the recovery phrase offline, in the displayed order.
4. Complete the phrase confirmation.
5. Set a strong local password.
6. On mobile, optionally enable biometric unlock when the device supports it.

The password encrypts the wallet vault on this device. It does not replace the recovery phrase.

## Restore a wallet

1. Choose **Restore wallet**.
2. Enter the recovery phrase in the correct order.
3. Set a new password for this installation.
4. Verify the first derived account addresses before moving funds.

Restoring a wallet does not recover a forgotten Salmon password. It creates a new encrypted installation from the recovery phrase.

## Derived accounts

One recovery phrase can produce multiple accounts. Salmon tracks their derivation index and can add or switch between them from **Settings → Accounts**.

Salmon uses these derivation paths:

- Solana: `m/44'/501'/{index}'/0'`
- Bitcoin: `m/44'/0'/{index}'/0/0`

When restoring in another wallet, the recovery phrase alone may not show the expected address if that wallet uses a different path or account index.

## Check your backup

Before depositing a significant amount:

- Confirm every recovery word and its order.
- Store the backup offline in a private, durable location.
- Make sure trusted people cannot accidentally discard it.
- Never test the phrase by entering it into a website.
