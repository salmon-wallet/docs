Salmon versions its applications independently. A mobile release, browser-extension release, and backend deployment do not necessarily happen together.

Current source versions at the time of this documentation update:

- Browser extension: `0.13.1`
- Mobile application: `1.0.3`
- Backend API: `0.16.0`

Use the version displayed by your installed application and the release history of its source repository when troubleshooting.

## Release sources

- Product announcements: [Salmon blog](https://medium.com/@salmonwallet)
- Frontend history: `CHANGELOG.md` in the frontend repository
- Backend history: `CHANGELOG.md` in the backend repository
- Extension store listing: follow the official link from [salmonwallet.io](https://salmonwallet.io)

Announcements do not guarantee that a release has completed rollout on every platform. Store review and staged distribution can delay availability.
